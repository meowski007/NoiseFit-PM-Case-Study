# NoiseFit Sync Center — SVG Prototype Screens

These are proposed portfolio-concept UI screens, not screenshots of the current NoiseFit app.

Flow:
1. Dashboard — Healthy
2. Sync Center — Syncing
3. Sync Center — Partial Sync
4. Sync Details — Failure
5. Bluetooth Recovery
6. Sync Center — Recovering
7. Sync Center — Success
8. Sync History

Design principle: Detect → Explain → Recover → Confirm.
